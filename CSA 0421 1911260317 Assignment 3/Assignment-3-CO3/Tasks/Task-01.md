# Task 1 – Logical Agents and Wumpus World

Encode pit, Wumpus, breeze and stench propositions for each square. Derive the breeze/stench neighbour rules, count symbols and models, and explain soundness and completeness. Test entailed, contradicted and unknown queries with a truth-table checker. Derive at least two safe-square conclusions using Modus Ponens, And-Elimination or Unit Resolution; include truth tables and compare inference steps with model checking.

## Evidence checklist
- Design and pseudocode before implementation
- Manual derivation and trace
- Reproducible source and inputs
- Expected versus actual output
- Operation counts and timing
- Boundary/failure test and interpretation
