# Task 4 – Unification and Lifted Inference

Show five hand-derived most general unifiers (MGUs), including an occurs-check failure and a standardise-apart case. Test the recursive unifier. Measure ground-clause growth for 3–30 constants and increasing predicate arity; add a function symbol and measure term growth by depth. Compare lifted and propositional inference and justify when grounding is preferable.

## Evidence checklist
- Five manual unification examples
- Occurs-check and standardise-apart demonstrations
- Source code and test cases
- Expected versus actual substitutions
- Grounding/lifted inference measurements
- Interpretation
