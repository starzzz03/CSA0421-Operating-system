# Task 2 – Model Checking versus Resolution

Build a smart-building access policy with at least ten rules, including implication, biconditional and disjunction. Convert three statements to CNF by hand and show a resolution-refutation proof. Extend the code with tautology removal and subsumption. Compare model enumeration and resolution attempts for chain lengths 10, 20, 40 and 80, and design knowledge-base families where each method performs better.

## Evidence checklist
- Design and pseudocode before implementation
- Manual derivation and trace
- Reproducible source and inputs
- Expected versus actual output
- Operation counts and timing
- Boundary/failure test and interpretation
