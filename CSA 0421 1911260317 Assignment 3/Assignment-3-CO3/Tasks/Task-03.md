# Task 3 – Knowledge Engineering in First-Order Logic

Model exam eligibility with predicates for student, course, attendance, prerequisites, fees, discipline, approved leave and eligibility. Write at least 12 quantified axioms including an existential. Compare repeated propositional rules (growth O(sc)) with reusable FOL axioms. Create 15 queries: five true, five false and five binding queries; record three knowledge-base defects and fixes.

## Evidence checklist
- Predicate vocabulary and quantified axioms
- Query set and answers
- Knowledge-base defect/fix table
- Reproducible source and inputs
- Expected versus actual output
- Complexity and timing interpretation
